Key responsibilities:
├── network_scanner/__main__.py
│   └── Module entrypoint for python -m network_scanner
├── network_scanner/scanner/main.py
│   └── CLI orchestration and command routing
├── network_scanner/scanner/scan.py
│   └── NetworkScanner class, host scanning, service scanning, progress callbacks, and scan flow
├── network_scanner/scanner/report.py
│   └── Colors, report mixin, summaries, and JSON/HTML/CSV/Markdown report generation
├── network_scanner/scanner/comparaison.py
│   └── Multi-report vulnerability trend report generation
├── network_scanner/scanner/parser.py
│   └── CLI parser, port parsing, proxy validation, and proxy masking
├── network_scanner/scanner/__init__.py
│   └── Public scanner package exports for backward-compatible imports
├── network_scanner/core/ui.py
│   └── Interactive TUI for scan setup, saved target profiles, scan progress, external-tool listing, and JSON report review
├── network_scanner/modules/ping_sweep.py
│   └── Host discovery with ICMP and TCP fallback probes
├── network_scanner/modules/port_scanner.py
│   └── Async TCP connect scanning
├── network_scanner/modules/service_scan.py
│   └── Service names, banners, HTTP metadata, TLS metadata, proxy-aware web requests, and web path probing
├── network_scanner/checks/
│   └── Built-in exposure checks and check framework
├── network_scanner/modules/risk.py
│   └── Service risk factors and severity scoring
├── network_scanner/modules/report_diff.py
│   └── Point-in-time report diffs and multi-report vulnerability trend analysis
├── network_scanner/modules/brute_force/
│   └── Guarded credential-audit compatibility helpers, not exposed by the main CLI
└── config/exploit_config.yaml
    └── Documents disabled exploitation-oriented legacy settings
