Key responsibilities:
├── network_scanner/scanner.py
│   └── CLI entrypoint, orchestration, summaries, and JSON/HTML/CSV/Markdown reports
├── network_scanner/core/ui.py
│   └── Interactive TUI for scan setup, external-tool listing, and JSON report review
├── network_scanner/modules/ping_sweep.py
│   └── Host discovery with ICMP and TCP fallback probes
├── network_scanner/modules/port_scanner.py
│   └── Async TCP connect scanning
├── network_scanner/modules/service_scan.py
│   └── Service names, banners, HTTP metadata, TLS metadata, proxy-aware web requests, and web path probing
├── network_scanner/checks/
│   └── Built-in exposure checks and check framework
├── network_scanner/modules/risk.py
│   └── Service risk factors and severity scoring
├── network_scanner/modules/report_diff.py
│   └── Point-in-time report diffs and multi-report vulnerability trend analysis
├── network_scanner/modules/brute_force/
│   └── Guarded credential-audit compatibility helpers, not exposed by the main CLI
└── config/exploit_config.yaml
    └── Documents disabled exploitation-oriented legacy settings
