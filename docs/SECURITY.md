# Security Policy

BlackScan is intended for authorized security assessment and internal asset review only.

## Reporting Issues

Please open a private security advisory or contact the maintainer privately for vulnerabilities in BlackScan itself.

Do not report findings from third-party systems unless you have authorization to test them.

## Scope

Acceptable project issues include:

- Incorrect or unsafe scanner behavior.
- False positives or false negatives in non-destructive checks.
- Report generation bugs.
- Dependency security issues.
